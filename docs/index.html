How to use it

About six minutes: you follow one incident from the learner's error page to the resolved ticket.

  1. Open the app. The free hosting sleeps when idle, so the first load can take about a minute.
  2. See it as the learner: Learner view → choose Sam Richter in the support bar → test the course link KWM-HY-201. Note the error code and request ID.
  3. Pick up the ticket: Tickets → SD-104. The request trail shows the reason from the log.
  4. Confirm with SQL: open the knowledge base article, run Why can't a learner see a course?. Verdict: group mismatch.
  5. Resolve: move to In analysis, then Resolved with root cause and resolution. Without a root cause the app refuses.
  6. Try more: SD-108 (broken XML, reproduce it in Course packages), SD-103, SD-107. Export for Jira as CSV.

All data is sample data and resets when the server restarts.
