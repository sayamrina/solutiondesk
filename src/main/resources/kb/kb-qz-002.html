Symptom

A learner reports that the result does not appear in the report. The error page shows SD-QZ-002.

How to check

  1. Open the request trail: the log line names the enrollment ID and the end date.
  2. Run the diagnostic Enrollments and quiz results of a learner with the learner's e-mail address.

Solution

This is expected behaviour, not a bug. The customer's training coordinator extends the enrollment; then the learner submits the quiz again. Tell the learner that the earlier attempts were not stored.
