Symptom

The user sees Something went wrong with SD-SYS-500 and a request ID.

What to collect before escalating

  1. The request trail of the request ID: exception, top frame in our code, path.
  2. In the log analysis, how often the error occurs and for which paths and customers.
  3. What the affected users have in common (group, course, browser) and a SQL diagnostic that shows it.
  4. A workaround, if one exists.

Escalation

Escalate to Development with these facts. A good escalation lets a developer reproduce the error without asking back.
