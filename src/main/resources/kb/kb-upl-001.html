Symptom

The upload stops with SD-UPL-001 and HTTP status 413.

Cause

The server accepts course packages up to 256 KB (spring.servlet.multipart.max-file-size). Large packages usually contain embedded images or videos.

Workaround

Import the course without embedded media and link the media from the media server instead.

Escalation

Raising the limit affects memory and storage on the server: escalate to Hosting with the request ID, the file size and the customer's reason.
