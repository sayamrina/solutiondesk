Symptom

The import stops with SD-IMP-005.

Why this is blocked

A DOCTYPE can define external entities that make the server read local files or call other servers (XXE attack). The platform never resolves them. Legitimate course packages do not need a DOCTYPE.

Solution

Remove the <!DOCTYPE …> line and any entity references such as &name;. If a package arrives with an entity that points to a system file, inform the customer's IT security contact.
