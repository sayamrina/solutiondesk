Symptom

The import stops with SD-IMP-002 and names the missing part, for example <metadata>/<title>.

Required parts

  • manifest/@identifier: the course code, unique per platform
  • metadata/title and metadata/targetGroup
  • at least one organization/item with a title
  • resources/resource with an identifier

Solution

Add the missing element and import again. Optional fields such as description and status (defaults to draft) can be left out.
