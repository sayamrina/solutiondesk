Symptom

The import stops with SD-IMP-001 and names a line and column.

Cause

  • An element is opened but never closed, or closed in the wrong order.
  • An attribute value is missing a quote.
  • A bare & or < appears in text outside a CDATA section.

How to check

  1. Open the request trail of the ticket's request ID: the log line contains the parser message, line and column.
  2. Open the file in an XML editor and go to the line before the reported one: the real mistake is often there, because the parser only notices it at the next tag.

Workaround / solution

Fix the tag structure and import again. If the package comes from an authoring tool, export it again and report the problem to the tool vendor.
