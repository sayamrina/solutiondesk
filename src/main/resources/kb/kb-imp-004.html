Symptom

The import stops with SD-IMP-004 and a line number. German titles with ä, ö, ü or ß are typical.

Cause

The first line declares encoding="UTF-8", but the file was saved by an older editor as Windows-1252. In Windows-1252, ü is the single byte 0xFC, which is not valid UTF-8.

How to check

Open the file in an editor that shows the encoding (e.g. Notepad++, VS Code: bottom right). A hex view shows a single byte between 0x80 and 0xFF where a two-byte UTF-8 sequence is expected.

Solution

Save the file as UTF-8 without BOM and import again. Do not change the encoding declaration to match a wrong file: keep UTF-8 as the standard.
