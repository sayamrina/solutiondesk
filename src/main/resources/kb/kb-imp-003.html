Symptom

The import stops with SD-IMP-003: item '…' points to resource '…', which does not exist.

Cause

Each <item identifierref="x"> must match a <resource identifier="x"> exactly. Identifiers are case-sensitive: f2 and F2 are different. Some authoring tools ignore case in their preview, so the problem only appears on import.

How to check

  1. Search the manifest for the identifier named in the error.
  2. Compare upper and lower case, and look for a resource that was renamed or deleted.

Solution

Make the reference and the resource identifier identical, then import again.
